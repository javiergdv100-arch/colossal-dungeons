# Colossal Dungeons Enhanced — Documento de diseño (web)

Sitio web del documento maestro de diseño y producción del mod **Colossal Dungeons Enhanced** para Minecraft 1.21.1 · NeoForge.

## Contenido

- **7 dungeons** colosales con fichas completas: identidad, regla exclusiva, sectores, jefe, semijefes, puzles, trampas, loot, eventos y secretos.
- **Bestiario de 70 criaturas** filtrable por dungeon y por rango, con ficha detallada (vida, armadura, daño, comportamiento y botín).
- Catálogo de **trampas**, **puzles** y **mecanismos**, con los añadidos NUEVOS por dungeon.
- **NPCs** y campamento, incluido Valdris el Eterno.
- **Dependencias**: el motor de VFX pasa de Photon a **AAA Particles** (efectos Effekseer).
- **Rendimiento** y **roadmap** de producción.

## Cómo verlo

- **Un solo archivo:** abre `colossal-dungeons-enhanced.html` en cualquier navegador (CSS, JS y datos incrustados, sin dependencias).
- **Versión modular:** abre `index.html` (usa `styles.css`, `app.js` y `data.js`).

## Publicar en GitHub Pages

En **Settings → Pages**, elige la rama a servir (por ejemplo `main` tras fusionar) y la raíz `/`. La web quedará en:

```
https://javiergdv100-arch.github.io/colossal-dungeons/
```
