Colossal Dungeons Enhanced

Plan Tecnico de Implementacion Completo

NeoForge 1.21.1 • Java 21 • Mojang Official Mappings • Mod ID: colossal_dungeons_enhanced

1. Vision General

Colossal Dungeons Enhanced es un mod de mazmorras para Minecraft 1.21.1 (NeoForge) que transforma la experiencia de exploracion. Cada dungeon es una estructura masiva con decenas de salas interconectadas, trampas mecanicas, puzles ambientales y jefes con fases multiples.

Principios Fundamentales

  • Vanilla-first: Los items vanilla de Minecraft siempre tienen uso en las dungeons. Polvo de hueso limpia aceite, miel da inmunidad al hielo, cubos de nieve crean plataformas temporales.
  • Data-driven: Todo el contenido (trampas, puzles, criaturas, rooms) se define via JSON. Addons y datapacks pueden extender sin tocar codigo.
  • Performance-oriented: Solo 1-3 salas activas simultaneamente. Salas inactivas suspenden AI, tick de BlockEntities y rendering de VFX.
  • Event-driven: Comunicacion entre sistemas via NeoForge Event Bus. Desacoplamiento total entre modulos.
  • Composicion sobre herencia: Interfaces y composicion de comportamientos en lugar de jerarquias profundas.
  • API publica: Framework extensible para que otros mods puedan anadir dungeons, criaturas y mecanicas.

2. Arquitectura General

El mod se organiza en capas bien definidas con comunicacion unidireccional descendente y eventos ascendentes.

+=============================================+ | CLIENT LAYER | +=============================================+ | Renderers (GeckoLib) | Particles (AAA) | | GUI/HUD/Overlays | Sound Manager | +=============================================+ | ^ v (render requests) | (sync payloads S2C) +=============================================+ | NETWORK LAYER | +=============================================+ | S2C: Room/Boss/VFX/Trap sync payloads | | C2S: Interact/Dialogue/Mechanism/Order | +=============================================+ | ^ v | (events) +=============================================+ | GAME LOGIC LAYER | +=============================================+ | DungeonManager | RoomController | Combat | | TrapFramework | PuzzleEngine | Effects | | VanillaInteract | Resonance | NPCs | +=============================================+ | ^ v (read/write) | (Codec serialize) +=============================================+ | DATA/PERSISTENCE LAYER | +=============================================+ | AttachmentTypes (Player + Level) | | JSON Configs (datapacks) | | SavedData per dimension | +=============================================+

Flujo de una Interaccion Tipica

  1. El jugador usa un item vanilla (ej: bone meal) sobre un bloque del mod (ej: oil_surface)
  2. VanillaInteractionHandler intercepta PlayerInteractEvent.RightClickBlock
  3. Busca en InteractionRegistry la combinacion item + target + context
  4. Ejecuta el efecto (IVanillaInteraction.apply())
  5. Dispara VanillaItemUsedInDungeonEvent en el NeoForge Event Bus
  6. El sistema de VFX escucha el evento y spawna particulas de limpieza
  7. Se envia VFXSpawnPayload (S2C) a todos los clientes en rango
  8. El cliente renderiza el efecto AAA Particles

5. Sistemas Core (12 Sistemas)

El mod se compone de 12 sistemas interconectados que se comunican via Event Bus de NeoForge.

5.1 Dungeon State Machine

Gestiona el ciclo de vida completo de cada dungeon: descubrimiento, entrada, activacion de salas, completado y reinicio.

Clases:

DungeonManager, DungeonInstance, DungeonState, DungeonSaveData, DungeonDefinition

Eventos:

DungeonEnteredEventRoomActivatedEventDungeonCompletedEventDungeonResetEventSectorTransitionEvent

Persistencia via NeoForge AttachmentTypes en Level (estado de dungeon) y Player (progreso individual). Serializa con Codec.

5.2 Room Activation System

Controla que salas estan activas. Solo 1-3 salas activas simultaneamente para rendimiento.

Estados:

UNLOADEDPREPAREDACTIVECOMPLETEDDORMANTSUSPENDED

Clases:

RoomController, RoomState, RoomBounds, RoomActivationHandler, RoomTransition

Rendimiento: Salas UNLOADED/DORMANT deshabilitan AI, BlockEntity tick, VFX y collision avanzada.

5.3 Trap Framework

Framework completo con Template Method para ciclo de vida, Strategy para activadores y Observer para chain reactions.

Clases:

AbstractTrap, TrapActivator, TrapConfig, TrapRegistry, ITrapBehavior, TrapChainReaction, VanillaTrapInteraction

  • Template Method: prepare() → arm() → trigger() → damage() → reset()
  • Strategy: PressureActivator, ProximityActivator, TimerActivator, ManualActivator
  • Observer: Chain reactions entre trampas conectadas

5.4 Puzzle Engine

Motor de puzles con estados, validacion de solucion y feedback visual/sonoro.

Clases:

PuzzleEngine, IPuzzle, PuzzleState, PuzzleSolver, PuzzleValidator, PuzzleFeedback

Tipos: Secuencia de sonido, Redireccion de luz, Peso/balance, Hidraulico, Patrones, Cooperativo.

5.5 Mechanism System

Mecanismos interactivos como BlockEntity con estado sincronizado.

Clases:

IMechanism, MechanismBlockEntity, HydraulicActivator, BalanceScale, Winch, PushableBlock, BrazierBlock, GoldenMechanism

Command pattern para activaciones. State para niveles de llenado/carga.

5.6 Vanilla Item Interaction System

Sistema central: intercepta uso de items vanilla en contexto de dungeon. Filosofia "vanilla-first".

Clases:

VanillaInteractionHandler, IVanillaInteraction, InteractionRegistry, InteractionContext, InteractionResult

Ejemplos:
  • Bone Meal + Oil: Limpia aceite + 30min proteccion
  • Honey + Ice: Elimina deslizamiento
  • Fishing Rod + Mirror: Gira espejos a distancia
  • Powder Snow + Abyss: Plataformas temporales (15-30s)
  • Milk + Any Debuff: Limpia TODOS los debuffs del mod
  • TNT + Weak Wall: Destruye paredes marcadas
  • Torch + Invisible: Revela enemigos invisibles

Evento: VanillaItemUsedInDungeonEvent

5.7 Resonance System

Cristales que absorben vibraciones. 4 estados: DORMANT, CHARGING, CHARGED, OVERLOADED.

Clases:

ResonanceCrystal, ResonanceVein, ResonanceState, ResonanceNetwork, ResonanceOverloadEvent

Integra con Sculk Sensors, Note Blocks y Campanas vanilla. TNT causa overload instantaneo.

5.8 Combat System

Combate con partes rompibles, fases de jefe, ataques telegrafados y dano localizado.

Clases:

CDECombatHandler, BossPhaseManager, AttackPattern, TelegraphedAttack, PartDamageHandler, MultipartEntityBase

5.9 VFX System (AAA Particles)

Gestiona efectos Effekseer con bone attachment a GeckoLib y pool de reutilizacion.

Clases:

CDEEffectManager, CDEEffectInstance, CDEBoneAttachment, EffectPool, EffectDefinition

Optimizacion: Pool reutilizable, solo sala activa renderiza, LOD por distancia, culling por frustum.

5.10 Dialogue and NPC System

Dialogos data-driven con arboles de decision, condiciones y memoria por jugador.

Clases:

DialogueTree, DialogueNode, DialogueChoice, DialogueCondition, NPCMemory, DialogueRenderer

5.11 Companion System

Companeros con AI, inventario propio y contribucion a puzles cooperativos.

Clases:

CompanionEntity, CompanionAI, CompanionInventory, CompanionOrder, CompanionState

Modos: FOLLOW, WAIT, ATTACK, EXPLORE. Reaccionan a trampas y participan en combate.

5.12 Addon API

API publica para extensibilidad via otros mods.

Clases:

CDEApi, IAddonProvider, AddonRegistry, AddonDungeonDefinition, AddonContentPack

Service Locator + Registry pattern + Event-driven integration.

6. Integracion de APIs Externas

6.1 GeckoLib 4.x (Animaciones)

Version: GeckoLib 4.x para NeoForge 1.21.1

  • Entidades animadas extienden GeoEntity, implementan getAnimatableInstanceCache() y registerControllers()
  • Modelos .geo.json en assets/cde/geo/
  • Animaciones .animation.json con KeyframeEvents para sincronizar sonido/particulas
  • Renderers extienden GeoEntityRenderer con layers custom

Clases wrapper: CDEGeoEntity, CDEGeoModel, CDEAnimationController, CDEGeoBlockEntity

6.2 AAA Particles (Effekseer)

Efectos .efkefc cargados como recursos, spawneados via EffekseerEffect.create(level, pos, rotation, scale). Bone attachment para sync con GeckoLib. Lifecycle con callbacks onComplete.

Clases: CDEEffectManager, CDEEffectInstance, CDEBoneAttachment

6.3 SmartBrainLib (AI Avanzada)

Wrapper sobre Brain API. Sensors + MemoryModules + Behaviors componen arboles de AI sin boilerplate.

Clases: CDEBrainProvider, CDESensor, CDEBehavior, CDEBossAI

Custom sensors: VibracionSensor, LightLevelSensor, PlayerProximitySensor.

6.5 NeoForge Systems

AttachmentTypes

Reemplaza Capabilities. Progreso, estado de sala, datos de companero. Serializa con Codec.

Event Bus

IEventBus (mod) para lifecycle. NeoForge.EVENT_BUS (game) para gameplay: LivingHurtEvent, PlayerInteractEvent, BlockEvent, ServerTickEvent.

Networking

Records + CustomPacketPayload + StreamCodec. Registrados en RegisterPayloadHandlersEvent.

DataGen

Extends DataProvider para JSON schemas custom. Genera recipes, loot, tags, advancements y configs.

7.1 Clase Principal del Mod (@Mod)

package com.colossaldungeons.enhanced;

import com.colossaldungeons.enhanced.core.registry.*;
import com.colossaldungeons.enhanced.network.CDENetworking;
import net.neoforged.bus.api.IEventBus;
import net.neoforged.fml.common.Mod;
import net.neoforged.fml.event.lifecycle.FMLCommonSetupEvent;
import org.slf4j.Logger;
import org.slf4j.LoggerFactory;

@Mod(ColossalDungeons.MOD_ID)
public class ColossalDungeons {

    public static final String MOD_ID = "colossal_dungeons_enhanced";
    private static final Logger LOGGER = LoggerFactory.getLogger(ColossalDungeons.class);

    public ColossalDungeons(IEventBus modBus) {
        LOGGER.info("Initializing Colossal Dungeons Enhanced...");

        // Registrar todos los DeferredRegisters al mod event bus
        CDEBlocks.register(modBus);
        CDEItems.register(modBus);
        CDEEntities.register(modBus);
        CDEEffects.register(modBus);
        CDESounds.register(modBus);
        CDEParticles.register(modBus);
        CDEAttachments.register(modBus);
        CDECreativeTabs.register(modBus);

        // Mod bus listeners (lifecycle)
        modBus.addListener(this::onCommonSetup);
        modBus.addListener(CDENetworking::registerPayloads);

        // Game bus: handlers registrados via @EventBusSubscriber (ver ejemplo abajo)
        // VanillaInteractionHandler, DungeonEventHandler, CombatEventHandler
        // usan @EventBusSubscriber(modid = MOD_ID, bus = Bus.GAME)
    }

    private void onCommonSetup(FMLCommonSetupEvent event) {
        event.enqueueWork(() -> {
            InteractionRegistry.initialize();
            TrapRegistry.initialize();
            LOGGER.info("CDE common setup complete");
        });
    }
}

package com.colossaldungeons.enhanced.entity;

import net.minecraft.world.entity.EntityType;
import net.minecraft.world.entity.PathfinderMob;
import net.minecraft.world.entity.ai.attributes.AttributeSupplier;
import net.minecraft.world.entity.ai.attributes.Attributes;
import net.minecraft.world.level.Level;
import software.bernie.geckolib.animatable.GeoEntity;
import software.bernie.geckolib.animatable.instance.AnimatableInstanceCache;
import software.bernie.geckolib.animation.*;
import software.bernie.geckolib.util.GeckoLibUtil;

public class GelatinousCubeEntity extends PathfinderMob implements GeoEntity {

    private final AnimatableInstanceCache cache = GeckoLibUtil.createInstanceCache(this);

    private static final RawAnimation IDLE = RawAnimation.begin().thenLoop("animation.gelatinous_cube.idle");
    private static final RawAnimation MOVE = RawAnimation.begin().thenLoop("animation.gelatinous_cube.move");
    private static final RawAnimation ATTACK = RawAnimation.begin().thenPlay("animation.gelatinous_cube.attack");

    public GelatinousCubeEntity(EntityType<? extends PathfinderMob> type, Level level) {
        super(type, level);
    }

    public static AttributeSupplier.Builder createAttributes() {
        return PathfinderMob.createMobAttributes()
            .add(Attributes.MAX_HEALTH, 80.0)
            .add(Attributes.MOVEMENT_SPEED, 0.18)
            .add(Attributes.ATTACK_DAMAGE, 8.0)
            .add(Attributes.KNOCKBACK_RESISTANCE, 0.8);
    }

    @Override
    public void registerControllers(AnimatableManager.ControllerRegistrar controllers) {
        controllers.add(new AnimationController<>(this, "main", 5, state -> {
            if (state.isMoving()) return state.setAndContinue(MOVE);
            return state.setAndContinue(IDLE);
        }));
        controllers.add(new AnimationController<>(this, "attack", 0, state -> {
            if (this.swinging) return state.setAndContinue(ATTACK);
            return PlayState.STOP;
        }));
    }

    @Override
    public AnimatableInstanceCache getAnimatableInstanceCache() { return this.cache; }
}

7.5 AnimationController con Transiciones de Fase (Boss)

package com.colossaldungeons.enhanced.entity.boss;

import software.bernie.geckolib.animation.*;
import software.bernie.geckolib.animatable.GeoEntity;
import software.bernie.geckolib.animatable.instance.AnimatableInstanceCache;
import software.bernie.geckolib.util.GeckoLibUtil;
import net.minecraft.world.entity.monster.Monster;
import net.minecraft.world.entity.EntityType;
import net.minecraft.world.level.Level;

public class DyingAtlasEntity extends Monster implements GeoEntity {

    private final AnimatableInstanceCache cache = GeckoLibUtil.createInstanceCache(this);
    public enum BossPhase { DORMANT, AWAKENING, PHASE_1, TRANSITION_1_2, PHASE_2, TRANSITION_2_3, PHASE_3, DEATH }
    private BossPhase currentPhase = BossPhase.DORMANT;

    private static final RawAnimation DORMANT_IDLE = RawAnimation.begin().thenLoop("animation.dying_atlas.dormant");
    private static final RawAnimation PHASE1_IDLE = RawAnimation.begin().thenLoop("animation.dying_atlas.phase1_idle");
    private static final RawAnimation PHASE1_SLAM = RawAnimation.begin().thenPlay("animation.dying_atlas.slam");
    private static final RawAnimation PHASE_TRANSITION = RawAnimation.begin().thenPlay("animation.dying_atlas.transition");
    private static final RawAnimation PHASE3_RAGE = RawAnimation.begin().thenLoop("animation.dying_atlas.phase3_rage");
    private static final RawAnimation DEATH_ANIM = RawAnimation.begin().thenPlayAndHold("animation.dying_atlas.death");

    public DyingAtlasEntity(EntityType<? extends Monster> type, Level level) { super(type, level); }

    @Override
    public void registerControllers(AnimatableManager.ControllerRegistrar controllers) {
        controllers.add(new AnimationController<>(this, "phase_controller", 10, state -> {
            return switch (currentPhase) {
                case DORMANT -> state.setAndContinue(DORMANT_IDLE);
                case PHASE_1 -> state.setAndContinue(PHASE1_IDLE);
                case TRANSITION_1_2, TRANSITION_2_3 -> state.setAndContinue(PHASE_TRANSITION);
                case PHASE_3 -> state.setAndContinue(PHASE3_RAGE);
                case DEATH -> state.setAndContinue(DEATH_ANIM);
                default -> state.setAndContinue(PHASE1_IDLE);
            };
        }).setSoundKeyframeHandler(event -> {
            if (event.getKeyframeData().getSound().equals("slam_impact")) {
                this.level().playSound(null, this.blockPosition(),
                    CDESounds.BOSS_SLAM.get(), this.getSoundSource(), 2.0f, 0.8f);
            }
        }));
    }

    public void transitionToPhase(BossPhase newPhase) {
        this.currentPhase = newPhase;
        if (!this.level().isClientSide()) {
            CDENetworking.sendToTracking(this, new BossPhasePayload(this.getId(), newPhase.ordinal()));
        }
    }

    @Override
    public AnimatableInstanceCache getAnimatableInstanceCache() { return this.cache; }
}

7.6 AbstractTrap (Template Method Pattern)

package com.colossaldungeons.enhanced.dungeon.trap;

import net.minecraft.core.BlockPos;
import net.minecraft.server.level.ServerLevel;
import net.minecraft.world.entity.player.Player;
import net.minecraft.world.phys.AABB;
import java.util.List;

public abstract class AbstractTrap {

    public enum TrapState { INACTIVE, PREPARED, ARMED, TRIGGERED, COOLDOWN }

    protected TrapState state = TrapState.INACTIVE;
    protected final TrapConfig config;
    protected final BlockPos origin;
    protected TrapActivator activator;
    protected int cooldownTicks = 0;

    protected AbstractTrap(TrapConfig config, BlockPos origin) {
        this.config = config;
        this.origin = origin;
        this.activator = TrapActivator.fromConfig(config.activator());
    }

    /** Template Method - ciclo completo. NO override. */
    public final void tick(ServerLevel level) {
        switch (state) {
            case INACTIVE -> { if (shouldPrepare(level)) { prepare(level); state = TrapState.PREPARED; } }
            case PREPARED -> { if (shouldArm(level)) { arm(level); state = TrapState.ARMED; } }
            case ARMED -> { if (activator.shouldTrigger(level, origin)) { trigger(level); state = TrapState.TRIGGERED; } }
            case TRIGGERED -> {
                List<Player> targets = getTargetsInRange(level);
                if (!targets.isEmpty()) damage(level, targets);
                cooldownTicks = config.cooldownTicks();
                state = TrapState.COOLDOWN;
            }
            case COOLDOWN -> { if (--cooldownTicks <= 0) { reset(level); state = TrapState.INACTIVE; } }
        }
    }

    // Abstract extension points
    protected abstract boolean shouldPrepare(ServerLevel level);
    protected abstract boolean shouldArm(ServerLevel level);
    protected abstract void prepare(ServerLevel level);
    protected abstract void arm(ServerLevel level);
    protected abstract void trigger(ServerLevel level);
    protected abstract void damage(ServerLevel level, List<Player> targets);
    protected abstract void reset(ServerLevel level);

    protected List<Player> getTargetsInRange(ServerLevel level) {
        AABB hitbox = config.hitbox().move(origin);
        return level.getEntitiesOfClass(Player.class, hitbox,
            p -> !p.isCreative() && !p.isSpectator());
    }
}

import net.neoforged.fml.common.EventBusSubscriber;

@EventBusSubscriber(modid = ColossalDungeons.MOD_ID, bus = EventBusSubscriber.Bus.GAME)
public class VanillaInteractionHandler {

    @SubscribeEvent
    public static void onRightClickBlock(PlayerInteractEvent.RightClickBlock event) {
        if (event.getLevel().isClientSide()) return;

        ServerPlayer player = (ServerPlayer) event.getEntity();
        ServerLevel level = (ServerLevel) event.getLevel();
        BlockPos pos = event.getPos();
        ItemStack stack = event.getItemStack();
        BlockState blockState = level.getBlockState(pos);

        // Solo procesar en dungeon activa
        if (!DungeonManager.get(level).isPlayerInDungeon(player)) return;

        // Verificar cooldown
        InteractionCooldowns cd = player.getData(CDEAttachments.VANILLA_INTERACTION_COOLDOWN);
        if (cd.isOnCooldown(stack.getItem())) return;

        InteractionContext ctx = new InteractionContext(player, level, pos, blockState, stack,
            DungeonManager.get(level).getCurrentRoom(player));

        InteractionRegistry.findInteraction(ctx).ifPresent(interaction -> {
            if (interaction.canApply(ctx)) {
                InteractionResult result = interaction.apply(ctx);
                if (result == InteractionResult.SUCCESS) {
                    if (interaction.consumesItem()) stack.shrink(1);
                    cd.setCooldown(stack.getItem(), interaction.getCooldown());
                    player.setData(CDEAttachments.VANILLA_INTERACTION_COOLDOWN, cd);
                    NeoForge.EVENT_BUS.post(new VanillaItemUsedInDungeonEvent(player, stack.getItem(), pos, result));
                    event.setCanceled(true);
                }
            }
        });
    }
}

7.9 DungeonManager (Room State Machine)

package com.colossaldungeons.enhanced.dungeon;

import com.colossaldungeons.enhanced.dungeon.room.*;
import com.colossaldungeons.enhanced.network.*;
import net.minecraft.resources.ResourceLocation;
import net.minecraft.server.level.ServerLevel;
import net.minecraft.server.level.ServerPlayer;
import net.neoforged.bus.api.SubscribeEvent;
import net.neoforged.neoforge.event.tick.ServerTickEvent;
import java.util.*;

public class DungeonManager {

    private static final Map<ServerLevel, DungeonManager> INSTANCES = new WeakHashMap<>();
    private final ServerLevel level;
    private final Map<ResourceLocation, DungeonInstance> activeDungeons = new HashMap<>();
    private final Map<UUID, ResourceLocation> playerToDungeon = new HashMap<>();

    public static DungeonManager get(ServerLevel level) {
        return INSTANCES.computeIfAbsent(level, DungeonManager::new);
    }

    @SubscribeEvent
    public void onServerTick(ServerTickEvent.Post event) {
        for (DungeonInstance dungeon : activeDungeons.values()) {
            dungeon.tick(level);
            for (ServerPlayer player : getPlayersInDungeon(dungeon)) {
                checkRoomTransition(dungeon, player);
            }
        }
    }

    private void checkRoomTransition(DungeonInstance dungeon, ServerPlayer player) {
        RoomInstance current = dungeon.getRoomForPlayer(player);
        RoomInstance newRoom = dungeon.findRoomAt(player.blockPosition());
        if (newRoom != null && newRoom != current) {
            if (current != null) { current.onPlayerExit(player); deactivateIfEmpty(current); }
            activateRoom(newRoom, player);
            dungeon.setPlayerRoom(player, newRoom);
            CDENetworking.sendToPlayer(player, new RoomSyncPayload(newRoom.getId(), newRoom.getState().ordinal()));
        }
    }

    private void activateRoom(RoomInstance room, ServerPlayer player) {
        if (room.getState() == RoomState.UNLOADED || room.getState() == RoomState.DORMANT)
            room.setState(RoomState.PREPARED);
        if (room.getState() == RoomState.PREPARED) {
            room.setState(RoomState.ACTIVE);
            room.onPlayerEnter(player);
            room.enableTick();
        }
    }

    public boolean isPlayerInDungeon(ServerPlayer p) { return playerToDungeon.containsKey(p.getUUID()); }
    public RoomInstance getCurrentRoom(ServerPlayer p) {
        ResourceLocation id = playerToDungeon.get(p.getUUID());
        return id == null ? null : activeDungeons.get(id).getRoomForPlayer(p);
    }
}

7.14 Mecanica del Aceite (Bone Meal Cleanse)

package com.colossaldungeons.enhanced.vanilla.interactions;

import com.colossaldungeons.enhanced.core.registry.*;
import com.colossaldungeons.enhanced.network.*;
import com.colossaldungeons.enhanced.vanilla.*;
import net.minecraft.server.level.ServerLevel;
import net.minecraft.server.level.ServerPlayer;
import net.minecraft.sounds.SoundSource;
import net.minecraft.world.effect.MobEffectInstance;
import net.minecraft.world.item.Items;

/**
 * Bone Meal + Oil = Cleanse + 30min protection.
 * 1. Jugador pisa OilSurfaceBlock -> OiledEffect (fuego 2x, desliza)
 * 2. Bone Meal en OilBlock -> destruye bloque + limpia efecto
 * 3. Bone Meal + sneaking -> self-cleanse
 * 4. Aplica OilProtectionEffect (30 min, previene re-aplicacion)
 */
public class BoneMealOilInteraction implements IVanillaInteraction {

    private static final int PROTECTION_TICKS = 20 * 60 * 30; // 30 minutos

    @Override
    public boolean canApply(InteractionContext ctx) {
        if (!ctx.stack().is(Items.BONE_MEAL)) return false;
        boolean isOilBlock = ctx.blockState() != null
            && ctx.blockState().getBlock() instanceof OilSurfaceBlock;
        // DeferredHolder implements Holder<MobEffect> - no .get() needed in 1.21.1
        boolean playerOiled = ctx.player().hasEffect(CDEEffects.OILED);
        return isOilBlock || (ctx.player().isShiftKeyDown() && playerOiled);
    }

    @Override
    public InteractionResult apply(InteractionContext ctx) {
        ServerPlayer player = (ServerPlayer) ctx.player();
        ServerLevel level = (ServerLevel) ctx.level();

        // Limpiar bloque
        if (ctx.blockState() != null && ctx.blockState().getBlock() instanceof OilSurfaceBlock)
            level.removeBlock(ctx.pos(), false);

        // Limpiar efecto del jugador
        player.removeEffect(CDEEffects.OILED);

        // Proteccion 30 minutos
        player.addEffect(new MobEffectInstance(
            CDEEffects.OIL_PROTECTION, PROTECTION_TICKS, 0, false, true, true));

        // Feedback: sonido + VFX
        level.playSound(null, player.blockPosition(),
            CDESounds.BONE_MEAL_CLEANSE.get(), SoundSource.PLAYERS, 1.0f, 1.2f);
        CDENetworking.sendToTracking(player,
            new VFXSpawnPayload("bone_meal_cleanse", ctx.pos(), 1.2f));

        return InteractionResult.SUCCESS;
    }

    @Override public boolean consumesItem() { return true; }
    @Override public int getCooldown() { return 100; } // 5 seconds
}

11. Mecanica del Aceite (Detalle)

Ciclo de Vida

[OilSurfaceBlock en sala] --> [Jugador pisa] --> [Aplica OiledEffect nivel 1-3] | +--> [Toca fuego] --> Burning 2x duracion + propaga a aceite cercano | +--> [Bone Meal] --> Cleanse + OilProtection 30 min | +--> [Milk] --> Remove effect (sin protection) | +--> [Water Bucket en bloque] --> Steam explosion + remove block

OiledEffect (MobEffect)

  • Duracion: 60s base (hasta 3 stacks)
  • +100% dano de fuego por nivel
  • Friction -30% por nivel
  • Visual: overlay negro brillante
  • Propagacion: tocar otro jugador transfiere 1 nivel

OilSurfaceBlock

  • Block sin collision (tipo alfombra)
  • ignitedByLava(), altamente inflamable
  • Bone Meal: destruye + particulas verdes
  • Water: steam explosion (3 bloques, 2 hearts)
  • TNT: prende TODO aceite en 10 bloques

Proteccion Post-Limpieza

OilProtectionEffect (30 min): previene re-aplicacion. Elimina frustracion en salas con mucho aceite.

14. Framework y Principios

1. Data-Driven sobre Hard-Coded

Ningun valor numerico hard-coded. Todo en JSON. Balanceo sin recompilacion.

2. Composicion sobre Herencia

Jerarquias planas (max 2 niveles). Comportamiento via interfaces y delegation.

// Composicion plana:
DyingAtlasEntity extends Monster implements GeoEntity, IBossPhase, IMultipart
  - BossPhaseManager phaseManager
  - CDEBrainProvider brainProvider
  - MultipartHandler multipart

3. Event-Driven Communication

Sistemas no se llaman directamente. Todo via NeoForge Event Bus.

4. Lazy Activation

Solo 1-3 salas activas. AI solo tick en ACTIVE. VFX solo render en frustum.

5. Vanilla-First

Items vanilla siempre utiles. Bone Meal limpia aceite, Water apaga fuego, Fishing Rod manipula.

6. API Publica

Paquete api expone interfaces estables para addons.

7. Testeable

Interfaces para mock. Records inmutables y predecibles.
